CARA PAKAI
==========

1. Ekstrak semua file di folder ini (index.html + folder assets/).
2. Taruh gambar background pilihanmu di dalam folder "assets/" dan
   beri nama persis: background.jpg
   (kalau formatnya .png, ganti juga nama file di index.html:
   cari baris "assets/background.jpg" di bagian <style>, lalu ubah
   ekstensinya jadi .png)
3. Buka index.html langsung di browser (double click) — selesai.

Foto-foto konten (foto-intro.png, foto-edukasi.png, foto-skill.png,
foto-goals.png) sudah diambil otomatis dari PDF asli, jadi tidak perlu
diganti kecuali kamu mau pakai foto lain.

Struktur halaman mengikuti urutan PDF aslinya:
Cover -> Introduction -> My Education -> Personal Skill ->
Work Experience -> Things I Love -> My Growth -> My Future Goals ->
Thank You.

Ada navigasi titik di sisi kanan layar (desktop) untuk lompat antar
bagian, dan tombol panah di kanan atas tiap bagian untuk lanjut ke
bagian berikutnya.
